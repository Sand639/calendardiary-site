# 日記カレンダー（calendardiary-site）

iPhone アプリ「日記カレンダー」の、サポート・利用規約・プライバシーポリシーのページです。
GitHub Pages で公開しています：https://sand639.github.io/calendardiary-site/

- `index.html` … サポート（よくある質問・お問い合わせ）
- `terms.html` … 利用規約
- `privacy.html` … プライバシーポリシー

アプリ本体のリポジトリ（非公開）の `Documents/ストアに出す手順（1.0.0）.md` から管理しています。
内容を変えたときは、ページの「制定日」の下に改定日を書き足してください。
